# Project 3 - Salary Prediction

## Project Overview
This project focuses on predicting employee salaries using Machine Learning and Linear Regression.

## Objectives
- Analyse the salary dataset.
- Perform data cleaning.
- Conduct Exploratory Data Analysis.
- Implement Single Linear Regression.
- Implement Multiple Linear Regression.
- Evaluate model performance.
- Save the trained model.
