# Task 2 - Salary Prediction

## Overview

This project focuses on predicting employee salaries using Machine Learning and Linear Regression techniques.

The project includes data preprocessing, exploratory data analysis, model training, salary prediction, and model evaluation.

## Objectives

- Analyse the salary dataset.
- Perform data cleaning and preprocessing.
- Handle missing values and duplicate records.
- Conduct Exploratory Data Analysis (EDA).
- Implement Single Linear Regression.
- Implement Multiple Linear Regression.
- Evaluate model performance using RMSE, MAE, and R² Score.
- Compare regression models.
- Save the trained Machine Learning model.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
