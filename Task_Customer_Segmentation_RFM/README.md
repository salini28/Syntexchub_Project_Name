# Task  - Customer Segmentation Using RFM Analysis

## Project Overview
Customer segmentation using Recency, Frequency, and Monetary (RFM) analysis.

## Dataset
UCI Online Retail Dataset.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Customer Segments
- Loyal Customers
- Potential Loyal Customers
- At Risk Customers
- Lost Customers
- New Customers

## Results
Identified 4,338 customers across five customer segments.
